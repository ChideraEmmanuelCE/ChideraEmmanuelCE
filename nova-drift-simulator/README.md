# NOVA DRIFT — 3D Hover Simulator

A playable futuristic hovercraft simulator made with Three.js and vanilla JavaScript.

## Features
- 3D hovercraft with animated thrusters and banking.
- Procedural neon highway, arches, low-poly scenery, atmospheric fog.
- Obstacles, shield damage, cyan energy cores, infinite-distance mode.
- Third-person, cinematic and cockpit cameras.
- Speed, distance, shield, personal best (local storage), pause and restart.
- Keyboard + touch controls, optional generated sound.

## Controls
| Key | Action |
|---|---|
| A / D or Left / Right | Strafe |
| W / S or Up / Down | Altitude |
| Space | Boost |
| Shift | Brake |
| C | Switch camera |
| P / Escape | Pause |
| M | Sound |

Mobile users get touch controls.

## Running
Serve this directory with a static server, e.g. `python3 -m http.server 8080`, and open localhost:8080.
Three.js v0.170.0 loads from jsDelivr CDN. A network connection is required.
