# Bloom Lab

An interactive luminous garden built by Chidera Emmanuel. Tap to plant, change colours, turn on gentle musical notes, undo, or download a self-contained SVG of your artwork.

Open `index.html` in a modern browser. No dependencies, signup, API keys, or build step. This version runs entirely in your browser; gardens are not saved after refreshing. Export your garden to keep it.

Keyboard: focus the garden and use Enter or Space to plant. All controls support keyboard navigation. Motion follows your system's reduced motion preference.

## Publish

The folder can be hosted by any static host, including GitHub Pages. Pushing the source to a GitHub branch does not enable GitHub Pages automatically.
