# iPhone 18 Pro Max — cinematic editorial experience

A premium, accessible, independently created product presentation inspired by Apple's 2026 iPhone 18 Pro Max.

## Features
- Official Apple device photographs, not a procedural 3D handset.
- Cinematic 4-scene autoplay hero with pause/play, previous/next and scrubbing.
- Scroll reveal, parallax-like depth, interactive finish chooser, sticky navigation.
- Dark / light / system auto theme with persistent user preference.
- Responsive layout and prefers-reduced-motion support.
- Product lineup cards and links to Apple's official pages.

## Run locally
Open index.html in a browser, or serve the directory using `python -m http.server 8080`.

## Deploy
Connect this repository to Vercel with **Root Directory: iphone-18-pro-cinematic**, Framework preset **Other** (no build step, static HTML). The app's `vercel.json` controls headers and clean URLs.
